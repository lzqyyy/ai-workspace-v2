# AI Workspace V2.0 V0.2.0

- 发布日期：2026-11-23
- 发布类型：多人基础对话平台最小 MVP
- 分支：`main`
- 契约版本：OpenAPI `1.2.0`、Proto `1.2.0`、SSE `1.1.0`
- 数据库迁移：`001` 至 `009`

## 发布范围

V0.2.0 交付 Project-first 的多人多 Agent 基础对话平台：

- Project、ProjectMember 与 owner/editor/viewer 权限。
- 两名人类成员在同一 Project、同一共享 Conversation 中协作。
- 两个 Agent 归属各自 owner，并通过 Project Agent 映射共享使用。
- 同一 Conversation 单 active Run，发送与 retry 冲突返回 409。
- Conversation `run.available` SSE 发现新 Run，再使用既有 Run SSE 接收流式事件。
- 事件持久化、游标回放、刷新恢复和断线重连。
- PostgreSQL 固定上限连接池、获取超时、建连超时、空闲验证和失效连接丢弃。
- owner-only Project 软归档、脱敏审计读取和统一 role × action 授权。
- 原生 HTML/CSS/JavaScript Project-first 工作台。

## 已知限制

- Conversation SSE 当前由服务端按连接周期查询 PostgreSQL，规模化前需要降载或通知机制。
- 连接池失效连接首次使用时可能产生一轮瞬时 503，随后自动恢复。
- 仅支持同一 Conversation 单 active Run。
- 当前实时订阅聚焦活动 Conversation，其他 Conversation 依赖轮询和切换回放兜底。
- 未实现 Task/Handoff、私有 Conversation、文件、共享记忆、多 Run 并行和插件系统。
- 正式账号、管理员、登录限流、HTTPS 生产部署、备份和监控属于下一阶段。

## 升级说明

- 从 V0.1.x 升级时必须执行 `db/migrations/001` 至 `009`。
- 旧 API 调用方应使用 OpenAPI 1.2.0；`CheckPermission` 调用方必须提供 `project_id`。
- 本版本不修改端口和架构边界：浏览器仅访问 C++ 8080，Worker 仅通过 gRPC 50051 访问 Core。
