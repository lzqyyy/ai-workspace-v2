## 架构门禁

- Browser 只访问 C++ 8080。
- 5432、50051 未在 Compose 中发布到宿主机。
- Worker 不依赖 PostgreSQL 客户端，只通过 gRPC。
- 密钥引用和 Demo Seed 未包含任何真实 API Key。
- 审计记录不包含消息正文。
- 空库启动自动迁移：3 个迁移版本、2 个测试用户。

## 已知限制

- 本机未安装 Docker，Compose 文件做了静态校验与等价本地进程验证；部署环境仍需执行一次真实镜像构建。
- Mock 模型是默认验收 Provider；真实 OpenAI-compatible Provider 支持 HTTPS 流式解析，但未使用真实密钥做外部调用验收。
- SSE 当前由 C++ 定时轮询 PostgreSQL；MVP 可接受，后续可换 LISTEN/NOTIFY 而不改变契约。
